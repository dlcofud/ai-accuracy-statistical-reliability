# AI 정확도 90%는 얼마나 신뢰할 수 있을까?

전산수학 II Chapter 8 **참여도 추가 탐구** 재현 코드  
학번: **2026320029** · 이름: **이채령**

## 연구 질문

테스트 20개 중 18개를 맞힌 결과와, 1,000개 중 900개를 맞힌 결과는 모두 정확도 90%입니다. 하지만 표본 크기에 따라 **95% 신뢰구간의 폭**, **표준오차**, **귀무가설 기각 여부**가 달라지는지 확인합니다.

이 프로젝트의 두 데이터셋은 **가상의 이항 시행 사례**입니다. 실제 학습된 AI 모델을 평가한 결과가 아닙니다.

## 실행

Python 3.10 이상을 권장합니다.

```bash
python -m pip install -r requirements.txt
python analyze.py
python -m pytest -q
```

`outputs/accuracy_intervals.png`에 그래프가 생성됩니다. 선택적으로 시뮬레이션 횟수와 시드를 변경할 수 있습니다.

```bash
python analyze.py --repeats 50000 --seed 29
```

## 사용한 방법

- **정확도**: 정답 개수 `k / n`
- **추정 표준오차**: `sqrt(p_hat * (1-p_hat) / n)`
- **95% 신뢰구간**: **양측** Wilson score 구간 `binomtest(k,n).proportion_ci(0.95, method='wilson')`
- **유의확률**: `H0: p = 0.8`, `H1: p > 0.8`의 **단측 정확 이항검정** `binomtest(k,n,p=0.8,alternative='greater')`
- **유의수준**: `alpha = 0.05`
- **몬테카를로**: 실제 정답 확률 `p=0.9` 가정, `np.random.default_rng`를 사용해 각 n별로 독립적인 평가셋 10,000개 생성

**유의**: 신뢰구간은 양측 95%로 계산하고, 가설검정은 단측으로 수행합니다. 단측 `binomtest` 결과에 `.proportion_ci()`를 호출하면 단측 신뢰구간이 되므로 보고서의 결과와 다릅니다.

## 기대 결과

| n | k | 정확도 | 추정 표준오차 | 95% Wilson 구간 | 단측 p값 | 유의수준 0.05 결론 |
|---:|---:|---:|---:|---:|---:|---|
| 20 | 18 | 90.0% | 0.06708 | [69.9%, 97.2%] | 0.2060847 | 귀무가설을 기각하지 못함 |
| 1000 | 900 | 90.0% | 0.009487 | [88.0%, 91.7%] | 약 8.73e-18 | 귀무가설 기각 |

몬테카를로 출력은 의사난수로 만든 **실험 예시**이며 시드를 바꾸면 달라집니다. 반면 표의 신뢰구간과 정확 이항검정은 입력값으로부터 재현 가능한 수학적 계산 결과입니다.

## 해석과 한계

동일한 관측 정확도라도, 표본 수가 많을수록 통계적 추정 불확실성이 줄어듭니다. 표본 크기가 20에서 1,000으로 50배 늘면 같은 비율의 추정 표준오차는 `sqrt(50)`배 작아집니다.

이는 사례별 정오답이 **독립**이고 공통 확률을 갖는다고 가정합니다. 실제 AI 평가는 평가 데이터 누수, 중복·군집 문항, 클래스 불균형, 대표성 부족 등의 문제 때문에 더 까다롭습니다. 또한 **p값은 귀무가설이 참일 확률이 아닙니다.**
