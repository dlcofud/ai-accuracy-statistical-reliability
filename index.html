06 · 계산 원리

관측 정확도: p̂ = k / n

추정 표준오차: SE = √[p̂(1−p̂)/n]

Wilson 신뢰구간: 중심 (p̂+z²/2n)/(1+z²/n), 반폭 z√[p̂(1−p̂)/n+z²/(4n²)]/(1+z²/n)

단측 정확 이항검정: H₀에서 X ~ Binomial(n,p₀)일 때 P(X ≥ k) 또는 P(X ≤ k)를 계산합니다.

양측은 관측 사건보다 귀무가설 아래 확률질량이 작거나 같은 결과들의 확률을 합하는 정확 이항검정 방식입니다.

07 · 해석할 때 주의할 점

  • 가상의 평가 데이터입니다. 특정 AI를 학습·검증한 실제 결과가 아닙니다.
  • 이항 모형은 각 평가 결과가 동일한 성공 확률을 갖고 서로 독립적이라는 가정을 사용합니다.
  • 95% 신뢰구간은 한 번 계산한 구간에 실제 정확도가 95% 확률로 존재한다는 뜻이 아닙니다.
  • p값은 귀무가설이 참일 확률이 아닙니다. 관측 결과 이상의 극단적 결과가 귀무가설 아래 나올 확률입니다.
  • p값이 α 이상이어도 H₀가 참이라고 증명된 것은 아닙니다.
  • 평가 데이터의 대표성, 데이터 누수, 클래스 불균형도 정확도의 신뢰성을 좌우합니다.
